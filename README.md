# LocalReach Media website

Open `index.html` in your browser to preview the website.

## Free ways to publish
You can upload these three files to a static-site host such as GitHub Pages, Netlify, or Cloudflare Pages. Free-plan availability and limits can change, so confirm their current terms before publishing.

## Easiest option
1. Create an account with a static-site host.
2. Upload this entire folder.
3. The service will give you a public website link.

## Important
The reservation form is currently a visual demo. To receive submissions and logo uploads, connect it to:
- Tally
- Jotform
- Formspree
- Google Forms

For a completely free first version, embed a Google Form or link the orange button to a Google Form.
