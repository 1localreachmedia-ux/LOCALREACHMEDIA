LOCALREACH MEDIA — EASY GITHUB REPLACEMENT

1. Download and UNZIP the package.
2. In your GitHub repository, delete the OLD website files you were using.
3. Click Add file > Upload files.
4. Upload ALL 7 files from this folder to the ROOT of the repository:
   index.html
   styles.css
   script.js
   privacy.html
   thank-you.html
   logo.png
   galveston-seawall.jpg
5. Click Commit changes.
6. Wait 1–2 minutes and refresh the live site.
7. Submit the reservation form once yourself. FormSubmit should send an activation email to 1LocalReachMedia@gmail.com. Open that email and activate the form. After activation, new submissions will be emailed there.

IMPORTANT: Do not upload the ZIP itself to GitHub. Upload the files inside it.
