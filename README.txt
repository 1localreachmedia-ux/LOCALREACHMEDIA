LOCALREACH MEDIA — EASY WEBSITE VERSION

This is the simple static version. No React. No Node.js. No coding software needed.

FILES TO UPLOAD TO GITHUB:
- index.html
- styles.css
- script.js

OPTIONAL:
- README.txt

HOW TO REPLACE YOUR CURRENT GITHUB PAGES WEBSITE:
1. Open your LOCALREACHMEDIA repository.
2. Delete the old:
   index.html
   styles.css
   script.js
3. Click Add file > Upload files.
4. Upload the 3 new files from this folder.
5. Commit changes.
6. Go to Settings > Pages.
7. Keep Source set to "Deploy from a branch".
8. Keep Branch set to "main" and folder "/ (root)".
9. Wait for GitHub Pages to redeploy.
10. Refresh your existing website URL.

IMPORTANT:
The reservation form currently LOOKS and BEHAVES correctly, but it does not send submissions anywhere yet.
The next step is to connect it to a free form service or a Google Form.

EASY EDITING:
To change text:
- Open index.html on GitHub.
- Click the pencil/edit icon.
- Find the wording you want to change.
- Edit it.
- Commit changes.
